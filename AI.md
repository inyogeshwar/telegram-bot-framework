# Telegram Bot Framework

This repository is a comprehensive developer handbook for building Telegram bots with Python.

## For AI Coding Agents

This repository is optimized for AI coding agents. See the agent-specific configuration files:

- **OpenCode**: `.opencode/config.json`
- **Claude Code**: `CLAUDE.md`
- **Cursor**: `.cursor/rules`
- **Cline**: `.clinerules`
- **RooCode**: `.roo/rules`
- **Continue.dev**: `.continue/config.yaml`
- **GitHub Copilot**: `.github/copilot-instructions.md`
- **Gemini CLI**: `.gemini/settings.json`

## Key Resources

- **Documentation**: `docs/` — 21-chapter developer handbook
- **Examples**: `examples/` — Production-quality bot examples
- **Skills**: `skills/` — AI agent skill definitions
- **Agents**: `agents/` — AI agent configurations
- **Templates**: `templates/` — Bot code templates
- **References**: `references/` — API quick reference

## Getting Started

1. Read `docs/README.md` for the table of contents
2. Check `examples/` for working code
3. Use `templates/` as starting points
4. Follow security guidelines in `docs/16-security-audit.md`

## Code Standards

- Python 3.9+
- python-telegram-bot v20+ (async/await)
- PEP 484 type hints
- PEP 8 style
- Error handling and logging
- Environment-based configuration
